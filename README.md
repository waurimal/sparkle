# ✨ Sparkle DIE (스파클 다이 다운 - 문장 릴레이 서바이벌)

초등학생을 위한 영어 문장 암기 & 릴레이 턴제 서바이벌 에듀테크 게임입니다.

## 📖 게임 소개
- **원작 규칙 반영**: 캔바 수업 프레젠테이션(Sparkle DIE - Lesson 9)의 영어 수업 활동 규칙을 디지털 인터랙티브 웹게임으로 완벽 구현!
- **문장 암기 페이즈 (Memorization)**: 문장과 해석, Skip 여부를 확인하고 제한 시간 동안 문장을 암기합니다.
- **단어 릴레이 페이즈 (Word Relay)**:
  - 플레이어들이 차례대로 돌아가며 문장의 다음 단어를 맞춥니다.
  - Skip 규칙 활성화 시 위험한 순간 Skip을 외쳐 살아남을 수 있습니다 (첫 단어 제외).
  - 단어를 틀리거나 시간 내에 입력하지 못하면 즉시 탈락(자리 앉기)!
- **피날레 3단 콤보 (Sparkle! DIE! DOWN!)**:
  - 문장이 완성된 직후, 다음 순번 플레이어들이 연속으로 외칩니다:
    - 🌟 **SPARKLE!** (생존 & 보너스 점수)
    - 💀 **DIE!** (생존 & 보너스 점수)
    - 🪑 **DOWN!** (자리 앉기! 탈락!)
- **선물 로또 추첨 (Lucky Draw)**:
  - 게임 종료 후 생존자들을 위한 3D 행운의 로또 추첨 머신 가동!

## 🎮 지원 모드
1. **개인전 (AI 배틀 모드)**:
   - 혼자서도 4인 / 6인 / 8인 AI 봇들과 긴장감 넘치는 서바이벌 대결!
   - 봇 난이도 및 랜덤 실수율을 적용하여 실제 반 친구들과 하는 듯한 생생한 몰입감 제공.
2. **실시간 멀티플레이 모드 (Firebase 연동)**:
   - 4자리 방 코드로 방 생성 및 입장.
   - 실시간 로비 대기실 및 참가자 아바타 카드 동기화.
   - 턴 순서, 시간 카운트다운, 생존/탈락 여부, 채팅/이모지 반응 실시간 반영.
   - 탈락 시 관전(Spectator) 모드 전환.

## 🏆 주요 편의 기능
- **골드 스탠다드 명예의 전당**:
  - 전체 / 이번 달 / 이번 주 기간별 필터 탭
  - 학년별, 반별, 단원별 세부 필터링 & TOP 30 랭킹 테이블
  - 학생 개인정보 보호를 위한 이름 마스킹(홍*동) 및 점수/탈락라운드/정확도 기록
- **교사 관리자 모드**:
  - 암호 보호 교사용 대시보드
  - 단원별 문장 추가/수정/삭제 및 커스텀 문장 등록
  - 랭킹 데이터 초기화 및 관리
- **풍부한 오디오 & 연출**:
  - Web Audio API 기반 순수 신디사이저 효과음 (외부 에셋 종속성 0%)
  - 화려한 Confetti 축하 효과 및 파티클 연출

## 🚀 기술 스택
- HTML5, Tailwind CSS, JavaScript (ES6+ Modules)
- Firebase Firestore (실시간 멀티플레이 방 관리 및 명예의 전당 랭킹 동기화)
- Web Audio API (사운드 효과음)
